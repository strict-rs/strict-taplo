# Migrating to Taplo `0.16`

Taplo `0.16` is a coordinated breaking release over `strict-logos 0.17` and `strict-rowan 0.17`. It keeps the Logos lexer and lossless Rowan tree while making construction failures, immutable semantic state, execution-model capabilities, and protocol concurrency explicit.

## Parsing and syntax kinds

`parser::parse` now separates tree-construction failure from recoverable TOML diagnostics:

```rust
use strict_test_support::TestFailure;
use strict_test_support::ensure;
use strict_test_support::ensure_ok;
use taplo::parser::parse;

fn parse_document(source: &str) -> Result<(), TestFailure> {
  let parsed = ensure_ok(parse(source), "the Rowan tree must construct")?;
  ensure(
    parsed.diagnostics().is_empty(),
    "the document must not contain recoverable TOML syntax diagnostics",
  )
}
```

`Parse` fields are private. Use `green()`, `diagnostics()`, `into_green()`, `into_syntax()`, and `into_dom()`. A successful `Parse` may contain ordered syntax diagnostics; `ParseFailure` is reserved for Rowan construction/protocol failure.

`SyntaxKind` is now a raw-kind newtype with documented constants such as `SyntaxKind::WHITESPACE`, `SyntaxKind::ROOT`, and `SyntaxKind::ERROR`. Use `SyntaxKind::from_raw(raw)` and `kind.raw()` for total conversion. `SyntaxKind` no longer implements `logos::Logos`; lexer derive/code generation is private.

## Immutable DOM and queries

DOM construction now freezes mutable build state into immutable `Arc`-backed nodes and collections. `Node`, concrete node wrappers, diagnostics, comments, and source anchors can be shared across threads.

Replace trait-based or generic indexing with explicit optional lookup:

```rust
use strict_test_support::TestFailure;
use strict_test_support::ensure_ok;
use strict_test_support::ensure_some;
use taplo::dom::Keys;
use taplo::parser::parse;

fn lookup_package_name(source: &str) -> Result<(), TestFailure> {
  let root = ensure_ok(parse(source), "the Rowan tree must construct")?.into_dom();
  let path = ensure_ok(
    "package.name".parse::<Keys>(),
    "package.name must be a valid TOML path",
  )?;
  let _name = ensure_some(root.path(&path), "package.name must exist")?;
  Ok(())
}
```

Use `Node::get`, `get_key`, `get_index`, and `path`, all of which return `Option<Node>`. Missing data is not malformed source. `Node::Invalid` is reserved for source that could not form a valid semantic scalar or structure, and its `InvalidReason` retains the intended kind, typed decode failure, and syntax anchor.

Semantic `dom::Error` is now `dom::Diagnostic`. Direct diagnostics are available through `errors()`, immutable table entries through `entries()`, and immutable array contents through `items()`. `Node::validate()` still collects diagnostics over the complete subtree.

## Formatting, rendering, and rewrites

Source formatter entry points now return typed errors because they parse:

```rust
let formatted = taplo::formatter::format(source, options)?;
```

`format_with_path_scopes` is likewise fallible. `format_green` and `format_syntax` remain infallible because their inputs already contain a successfully constructed tree.

DOM TOML emission returns `Result<String, RenderError>` and preflights the complete subtree before writing. `RenderError::InvalidNode` retains the malformed source reason for a `Node::Invalid`; `RenderError::SemanticDiagnostics` rejects conflicts and other diagnosed structures that do not have one unambiguous TOML representation. Detached keys are emitted as valid escaped basic keys when they are not bare keys.

The source-preserving rewrite model remains: `Rewrite`, `ExactPath`, fragments, `TomlKind`, `EditOutcome`, `Patch`, and pending patches retain their wire shapes and atomic overlap rules. `RewriteError::Parse` now carries `ParseFailure`, and the old `rewrite::Error` alias is removed. Syntax diagnostics, semantic diagnostics, missing or ambiguous paths, invalid fragments, range failures, overlaps, and unsupported placement remain distinct.

## Environment and schema capabilities

`Environment` now contains only synchronous host facts and stream constructors. Use `LocalEnvironment` for local asynchronous file/config operations and `spawn_local`; use `ConcurrentEnvironment` for `Send` futures and native spawning.

Native code uses `NativeEnvironment` and concurrent schema transport. WebAssembly uses `WasmEnvironment`, which implements only local capabilities and is constructed with `TryFrom<JsValue>`. JavaScript callbacks are validated during construction; missing functions, thrown or rejected calls, invalid values, malformed timestamps, and serialization errors surface as typed environment errors and become `JsError` only at the binding edge.

Schema interpretation is independent of transport. Select `LocalSchemaTransport`, `ConcurrentSchemaTransport`, or `OfflineSchemaTransport` according to the execution model and remote-access policy. Unsupported URL schemes and unavailable remote transport are errors rather than logging-only degradation.

## Local and concurrent language servers

The old `Server`, `ServerBuilder`, `Context`, and world aliases are removed.

The protocol runtime package is now published as `taplo-lsp-async`, and Rust source imports it as `taplo_lsp_async`. The temporary `lsp-async-stub` package and `lsp_async_stub` crate identifiers are removed rather than retained as compatibility aliases.

Custom local and concurrent message sinks now use `taplo_lsp_async::MessageWriterError`. Wrap host or stream failures with `MessageWriterError::from(io_error)`; the public variants retain their concrete sources in `Box<io::Error>` and `Box<futures::channel::mpsc::SendError>` so the enum remains compact without type erasure. Native output-queue closure remains `MessageWriterError::OutputChannelClosed`, while server-level raw stdio, TCP, and framing failures remain distinct as `ServerError::Io`.

For native execution:

```rust
let server = taplo_lsp::create_concurrent_server::<NativeEnvironment>();
let world = taplo_lsp::create_concurrent_world(environment, http_client)?;
```

For current-thread or WebAssembly execution:

```rust
let server = taplo_lsp::create_local_server::<WasmEnvironment>();
let world = taplo_lsp::create_local_world(environment, http_client)?;
```

State-changing notifications are serialized through one ordered mutation lane. Requests wait for prior mutations, clone immutable document/config/schema snapshots, execute independently, and suppress generation-dependent output when their captured revision becomes stale.

The mapper now consumes and returns `lsp_types::Position` and `lsp_types::Range` directly. Mapper construction and every conversion are fallible, with typed failures for oversized sources, invalid boundaries, out-of-bounds positions, reversed ranges, underflow, and overflow.

Document symbols use a Taplo-owned modern DTO registered under the standard `textDocument/documentSymbol` method. Its JSON omits the deprecated field and retains standard `tags`.
